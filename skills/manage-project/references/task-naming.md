# Task naming has moved

The standalone [name-tasks skill](https://github.com/matijagrcic/codex-skills/blob/main/skills/name-tasks/SKILL.md) now owns title proposals and scoped renaming. Use its installed `SKILL.md` when available, or read the linked source for the guidance. This reference remains for existing links and chats.

A naming-only request does not start manager records, runners, or a heartbeat. `steer-work` remains usable without the companion skill.
